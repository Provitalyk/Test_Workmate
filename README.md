#  Анализ эффективности работы сотрудников
## Для генерации аналитических отчётов на основе данных из CSV‑файлов (отчёт по производительности сотрудников "performance")

# Функционал:
Загрузка данных из нескольких CSV‑файлов одновременно  
Парсинг CSV с автоматической обработкой заголовков  
Генерация отчёта:
- группировка данных по позициям;
- расчёт средней производительности;
- сортировка результатов по убыванию показателя
  
Обработка ошибок (отсутствие файлов, некорректные данные)  
Вывод отчёта в табличном формате в консоль

# Технологии:

pytest (для тестирования)  
tabulate (для форматированного вывода таблиц)  
mocker (для мокирования в тестах)  

# Запуск:

python main.py --files employees1.csv employees2.csv --report performance
